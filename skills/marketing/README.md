# Marketing Skills

Reusable marketing and growth skills for AI coding agents.

Vendored and adapted from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) and local workflows.

## Shared Context

Most marketing skills read `.agents/product-marketing.md` for foundational positioning, audience (ICP), value propositions, and tone of voice. Run `product-marketing` first in a new project to establish this context.

## Skills

| Skill | Description |
|---|---|
| `product-marketing` | Create or update the product marketing context document (`.agents/product-marketing.md`) capturing positioning, ICP, and UVP. |
| `customer-research` | Conduct, analyze, and synthesize customer research, user interview transcripts, surveys, review mining, and Jobs-to-be-Done (JTBD). |
| `copywriting` | Write and improve marketing copy for homepages, landing pages, feature pages, and product sections using conversion frameworks. |
| `cro` | Audit and optimize marketing pages and forms to eliminate friction and increase conversion rates. |
| `ad-creative` | Generate, iterate, and scale ad copy variations, headlines, hooks, and creative angles across paid ad platforms. |
| `seo-audit` | Audit, review, and diagnose technical and on-page SEO issues, metadata, and indexation health. |
| `ai-seo` | Optimize content for AI search engines (AEO/GEO) to get cited by ChatGPT, Perplexity, Claude, and Google AI Overviews. |
| `programmatic-seo` | Build SEO-driven page templates and data structures to capture high-intent search traffic at scale. |
| `content-strategy` | Plan content marketing roadmaps, topic clusters, search intent mapping, and editorial calendars. |
| `cold-email` | Write targeted B2B cold outreach emails and multi-touch follow-up sequences designed for high reply rates. |
| `review-marketing-copy` | Act as a creative director to critique, restructure, and rewrite marketing copy, value hierarchy, and narrative flow. |
