# Video & Design Skills

Reusable skills for AI filmmaking, character consistency, and presentation design.

## Shared Context

Story and character work is ordered. Do not skip steps.

1. `story-bible-builder` locks world, voice, movement, and production rules into an installable bible.
2. `character-builder` locks photoreal identity plates (face, outfits, sheets) on a flat 18% gray field.
3. Image and video directors consume those plates. They do not invent identity.

`frontend-slides` is separate. It is for HTML decks, not film prompts.

`character-builder` owns identity plates. `banana-pro-director-30` owns scene stills. Both can do face lock, outfits, and sheets; prefer `character-builder` for canonical character work.

## Skills

| Skill | Description |
|---|---|
| `story-bible-builder` | Interview-driven story bible. Outputs one installable `SKILL.md` covering premise, world, characters, voices, movement locks, and production rules. |
| `character-builder` | Photoreal Higgsfield / Nano Banana Pro character grammar. Face lock, additions, outfits, outfit replacement, and character sheets on a shadowless gray plate. |
| `banana-pro-director-30` | Higgsfield still-image director for Banana Pro, Soul Cinema, and GPT-2. Face lock, outfits, sheets, cinematic scene plates, and outfit swaps. |
| `cinema-director-v3` | Seedance 2.0/2.5 and Higgsfield video prompt grammar. Multi-shot production prompts on a locked 16-slot spine. Prefer this over earlier cinema-director versions. |
| `frontend-slides` | Zero-dependency animated HTML presentations from scratch or PPTX. Visual style discovery, fixed 1920x1080 stage. |

## Typical film path

`story-bible-builder` → `character-builder` → `banana-pro-director-30` (scene plates) → `cinema-director-v3`
